# Cake photography

The `placeholder-*.jpg` files here are generated stand-ins, not real work.
Replace them with real photographs and delete `scripts/generate-placeholders.ts`.

Guidance for real photos:

- At least 2000px on the long edge; originals preferred.
- Mixed orientations help the masonry grid look composed.
- Name them descriptively: `saffron-pistachio-2tier-01.jpg`.
